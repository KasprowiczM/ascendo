# Format (pipe-delimited, lines starting with # are comments):
#   display_name|package_name|method|brew_formula|command
#
# Methods:
#   native-node  — installed via `n` (Node version manager) under
#                  $TOOLCHAIN_HOME/node. Self-bootstraps via npm install -g n.
#   native-bun   — installed via curl https://bun.sh/install | bash
#                  under $BUN_INSTALL.
#   npm          — `npm install -g <package_name>`. Honors $NPM_GLOBAL_PREFIX.
#   native-installer — vendor install.sh into ~/.local/bin (claude, codex,
#                  agy, cursor-agent). Not the npm-global stub.
#   self-update  — the CLI updates itself: `<command> update` (opencode:
#                  native-first, `opencode upgrade --method curl` /
#                  https://opencode.ai/install; the npm distribution is only a
#                  guarded fallback, `opencode upgrade --method npm`, when an
#                  npm install of it already exists).
#
# Only-installed model: a CLI/Node/bun that is not installed is `skipped`
# ("not installed - skipping") unless ASCENDO_BOOTSTRAP_CLI=1 or it is named
# explicitly in --filter. Native installer / native-first rows run BEFORE
# Node/npm.
#
# brew_formula:  if non-empty, ascendo will prefer the npm-installed copy
#                and remove the Homebrew formula on apply (one-time
#                migration). Set to empty when no brew analog exists.
#
# command:       the binary name on PATH that proves the install worked.
#                Used by `verify` to confirm exit-code-0 on `<command> --version`.
