## [1.0.4] — 2026-08-26 — lock web apps to macOS_updates channels

### Changed

- **One installer path per app.** Web `check` / `plan` / `apply` skip
  Homebrew-preferred bundle IDs from `macos_app_sources.toml` (Zoom,
  Brave, Perplexity, LM Studio, ProtonVPN, MEGAsync, AppCleaner,
  Obsidian, Spotify, Inkscape, CapCut). Brew owns those casks.
- **Chrome and Google Drive** use Keystone (`ksadmin_product_id`), not
  the Chrome Version History API / Omaha. Sister channel is Google
  Software Update.
- **silent_launch apps** (ChatGPT, Codex, Claude, Warp, Gemini, Comet,
  Antigravity, Antigravity IDE, OpenCode, Cursor, Proton Mail) use the
  squirrel handler. Apply does hidden `open -gjF` even in safe mode
  (same as macOS_updates `silent_launch_app`). builtin still returns 95.
- **Docker Desktop** uses `docker desktop update --quiet`, not Sparkle.
- **Remote Desktop Manager and Proton Drive** use Sparkle. Empty
  `appcast_url` reads `SUFeedURL` from the installed Info.plist.
- **Firefox / VS Code / Ledger** stay on vendor feeds (Mozilla
  `download.mozilla.org`, `update.code.visualstudio.com`,
  `download.live.ledger.com` `files[dmg].url`). Sister
  `internet_app_methods.txt` labels them `github_dmg`; the sister
  *code* does not use GitHub. Ascendo follows the code.

### Coverage

- 43/43 names in sister `internet_apps.txt` share the effective channel.
  Previous comparative report: 25 same / 18 different drivers.

Do not copy `update_all.sh` wholesale. No live apply on the operator Mac
in this release.
