## [1.0.3] — 2026-08-26 — macOS inventory alignment + last-run repairs

### Fixed

- **Claude Desktop is web-only.** Removed the brew+web duplicate row from
  `adapters/macos/config/macos_app_sources.toml` (`id=claude` / `brew=claude`).
  Sister `internet_app_methods.txt` updates Claude via `silent_launch`; Ascendo
  keeps the `web` `release_feed` slug.
- **Ledger Live SHA512 / artifact pairing.** `web_apps.toml` uses
  `download_path = "files[dmg].url"`. `_rf_walk_json` maps `files[dmg].(url|sha512)`
  to the first `files[]` URL ending in `.dmg`.
- **Homebrew cask downgrade guard.** `ascendo_brew_cask_would_downgrade` skips
  check/plan/apply when the installed app is newer than the cask (Brave 151.x
  vs cask 1.93.x).
- **Native CLI installer timeout.** `ascendo_npm_run_with_timeout` wraps
  `curl | sh` in `scripts/npm/apply.sh`. Default 180s; exit **124** on timeout.
- **`softwareupdate -l --include-config-data`** on check/plan/apply/verify.
- **Microsoft Teams.** Not admin-installable via `msupdate --install --apps
  TEAMS21`. Apply stays **RC 95** GUI-gated.
- **iPad-on-Mac App Store apps.** UniFi, WiFiman, Picsart (not myCANAL) use
  the `mas` AppleScript GUI fallback.

### Docs

- `docs/last-run-review.md` — 2026-08-25 forensic table for sister log
  `logs/update_all_20260825_095956.log`.
