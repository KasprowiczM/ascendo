Hand off to Claude Code

The complete system lives in colors_and_type.css + HANDOFF.md. Drop both into your Ascendo repo at app/frontend/, link the CSS once at the top of index.html, and replace existing color/type rules with the semantic tokens (var(--bg), var(--accent), var(--fg-muted), etc.). Light is the default; data-theme="dark" on <html> flips it. See HANDOFF.md for the full migration map.
