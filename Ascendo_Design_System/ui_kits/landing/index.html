v0.1.0 · pre-release · MIT licensed

One tool to keep your machine up to date.
Everywhere.

Ascendo unifies OS updates, package managers, app stores, dev tools, drivers, and AI agent CLIs behind one CLI and one local dashboard. Linux, Windows, macOS — same five-phase pipeline.

Install for Linux → $brew install KasprowiczM/tap/ascendo

Linux MVP, ready first

Tested on Ubuntu 22.04 / 24.04, Debian 12, Pop!_OS. AUR build for Arch tracks main weekly. The Tauri shell wraps the same FastAPI backend used by the CLI.

Built for people who already know what apt full-upgrade does.

No marketing puff. Five phases, one orchestrator, JSON sidecar per phase. Read the code, write a plugin, hold the line on what gets installed.

Five-phase pipeline

check → plan → apply → verify → cleanup. Every category emits a JSON sidecar (schema v1) so dashboards, scripts, and CI can read state.

Snapshot before apply

timeshift on Linux, etckeeper fallback. Bounded by a 300s timeout — the run never stalls. Roll back from ascendo snapshot list.

Plugin-first

Tier-1 plugins ship with the binary (NVIDIA, Dell, agent CLIs). Tier-2 lives in contrib/. Author guide is one page.

Schedule on your terms

systemd timer with maintenance windows, AC-only, focus-aware. The scheduler runs the same code path as your CLI — no duplicated logic.

Multi-host preflight

Read-only SSH sweep across machines in config/hosts.toml. See OS, kernel, last run at a glance — no agent required.

AI suggestions, not auto-apply

Optional LLM enriches heuristic rules over your inventory. Always shown as a unified diff. Local providers (Ollama, LM Studio) supported. Never edits files autonomously.
